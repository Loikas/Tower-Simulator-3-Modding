# Available mods

The framework is shared infrastructure. The other mods are optional; install only the features you use.

| Mod | Current version | What it adds |
| --- | --- | --- |
| Mod Framework | 0.8.21 | Shared observations, mod settings, help and integration services |
| [Tug Operations](Tug-Operations.md) | 0.13.14 | Stand transfers, tow requests, runway protection and recovery towing |
| [Automatic Flight Strips](Automatic-Flight-Strips.md) | 0.6.6 | Runway/progress routing and completed-flight binning |
| [Rejected Takeoffs](Rejected-Takeoffs.md) | 0.5.2 | Occasional aborts, checks, recovery and maintenance |
| [Camera Tools](Camera-Tools.md) | 0.2.4 | Aircraft follow, orbit, extended zoom and shortcuts |
| [Aircraft Effects](Aircraft-Effects.md) | 0.2.5 | Touchdown smoke, wet spray and airport ambience |
| [Pilot Reports](Pilot-Reports.md) | 0.5.2 | Holding reports and ADIRS dashed hold routes |
| [Input Panel](Input-Panel.md) | 0.2.3 | Game/mod key bindings and modifier combinations |

These are current development versions, not a promise of compatibility with every future game build. [Compatibility](Compatibility.md) describes the tested baseline.

The separate External ADIRS component is an integration used by added displays; it is not a standalone package in the current launcher bundle. Follow the Pilot Reports/added-window workflow supplied with your build.

Window/overlay restoration and an option to keep the simulation running in the Escape menu are backlog ideas. They are not implemented features. Remote-parking scheduling and landing incidents remain deferred.
