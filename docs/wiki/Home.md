# TS3 Modding

Optional mods and shared services for Tower! Simulator 3.

Use the launcher to install the framework and choose the mods you want. Mod settings appear under **Settings > Mods**. Input Panel adds configurable shortcuts to **Settings > Input**.

## Current baseline

These pages describe framework **0.8.21**, API package **0.8.11** and the October 2026 development builds. The API DLL keeps assembly identity **0.2.0.0** for binary compatibility; this is not the framework's feature version. See [Compatibility](Compatibility.md).

The launcher, local store and authoring tools work locally. A public release service and published ModDB catalog are not available yet. This documentation is prepared for GitHub; it has not been published by this update.
