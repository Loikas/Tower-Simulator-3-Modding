# Camera Tools

Follow aircraft, orbit with the mouse and use extended zoom. Open the panel through **Settings > Input > Open Camera Tools**, or the default shortcut.

| Default shortcut | Action |
| --- | --- |
| Ctrl+Shift+C | Toggle the panel |
| Ctrl+Shift+F | Toggle following the selected aircraft |
| Ctrl+Shift+R | Restore the normal camera |

With Input Panel, change these bindings in the in-game Input menu. Without it, built-in fallback shortcuts remain available.

**Follow selected** uses the valid native command target, then persistent callsign-highlight selection. This matches the game's selection priority when the temporary command target clears. Deleted/inactive aircraft are excluded. The panel also offers an aircraft list.

Hold the right mouse button to orbit while following. The wheel adjusts follow distance, or FOV in extended-zoom mode. Separate X and Y drag inversion settings apply immediately. Escape restores the previous view; hiding the panel can keep follow active.

Native saved camera points and user-view restoration are not duplicated by this mod. Automatic added-window restoration remains a separate backlog idea.
